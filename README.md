#  FlyTrack — Pipeline DevOps CI/CD

## AeroPuerto Smart | Práctica universitaria de DevOps

Sistema de seguimiento de vuelos con pipeline DevOps completo:
automatización de pruebas, contenedorización con Docker y despliegue continuo mediante GitHub Actions.

---

## Integrantes

| Nombre | Rol DevOps |
|---|---|
| Integrante 1 | Investigación y diagnóstico |
| Integrante 2 | Desarrollo y pruebas |
| Integrante 3 | Contenedorización y despliegue |
| Integrante 4 | Documentación y presentación |

---

## Stack tecnológico

- **Lenguaje:** Python
- **Pruebas:** pytest
- **Contenedor:** Docker + Docker Compose
- **CI/CD:** GitHub Actions
- **Control de versiones:** Git + GitHub
